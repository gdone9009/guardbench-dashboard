일치 = 정답과 맞음 보안 회귀 = 막아야 할 걸 통과시킴 과잉 차단 = 정상을 잘못 막음 개선됨 = 예전 오류를 바로잡음 — 판정 안 됨 = 실행이 끝나지 않아 비교 불가

새 검증 실행

새 검증 실행

현재 운영 정책과 변경 예정 정책(초안)을 같은 테스트 묶음으로 비교합니다.

1. 테스트 범위

실행할 테스트 묶음을 선택하면 포함된 테스트가 스냅샷으로 복제됩니다.

2. 현재 운영 정책 (Baseline)

비교 기준이 되는, 지금 운영 중인 Guardrail 버전입니다.

3. 변경 예정 정책 (Candidate)

새로 배포하려는 정책입니다. 초안(DRAFT)은 실행 전 고정된 버전으로 발행됩니다.

초안을 직접 실행하지 않고, 고정된 버전으로 발행한 뒤 현재 정책과 동일한 테스트로 실행합니다.

핵심 도메인 규칙

01. 정답은 사람이 정의

Guardrail 출력 자체를 정답으로 쓰지 않습니다.

02. 동일 스냅샷 비교

현재/변경 예정 정책은 같은 불변 테스트를 공유합니다.

03. 실행과 판정 분리

실행 오류, 정답 불일치, 비교 불가는 서로 다릅니다.

04. 초안 고정

초안을 고정된 버전으로 발행한 뒤 실행합니다.

05. 배포 판정은 별도 축

실행 신뢰성이 부족하면 차단이 아니라 판정 불가입니다.
