AWS 인프라 핵심 토폴로지 구성 요약 (Topology Components)

VPC & Network Topology

Public Subnet(ALB, NAT Gateway)과 Private Subnet(ECS Fargate, RDS PostgreSQL)을 철저히 분리하여 보안 격리를 달성했습니다.

module.vpc

SQS 4-Queue Pipeline

FIFO 멱등성 큐, WorkItem 팬아웃 큐, Finalize 완료 시그널 큐, DLQ 장애 격리 큐 등 4대 비동기 메시지 파이프라인.

module.sqs

ECS Fargate Workers

서버리스 컨테이너 기반 엑세큐터 워커가 Amazon Bedrock `ApplyGuardrail` API를 수천 건 병렬 호출하여 평가를 수행합니다.

module.ecs

RDS PostgreSQL Multi-Schema

`test_runs`, `test_cases`, `test_case_snapshots` 스냅샷 테이블로 평가 이력과 불변 복사본을 안전하게 저장합니다.

module.rds

팀원 개인 AWS 계정 테라폼(Terraform) 실습 가이드

콘솔 클릭 없이 코드 한 줄로 5분 만에 동일 인프라를 복제 배포하고 요금 발생 없이 삭제합니다.

IaC Standard
🚀 1. 테라폼 인프라 5분 자동 배포 
git clone git@github.com:GuardBench/guardbench-iac.git
cd guardbench-iac

# 개인 계정 변수 설정 (terraform.tfvars)
aws_region  = "ap-northeast-2"
environment = "dev-myname"

# 자동 배포 실행
terraform init
terraform apply -auto-approve
🧹 2. 실습 후 과금 방지 전체 자동 삭제 
# 실습이 종료되면 생성되었던 
# VPC, SQS, ECS, RDS 자원 전체 삭제

terraform destroy -auto-approve

# 결과: AWS 요금 0원 유지!
